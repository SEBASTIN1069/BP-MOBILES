Storage security rules
=======================
Firebase console > Storage > "Rules" tab > paste this over the
existing rules > click "Publish".

Same idea as the Firestore rules: everyone can view photos, only your
logged-in admin account can upload or delete them.

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
